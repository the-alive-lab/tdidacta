# Relationships — relaciones conceptuales de TDidacta

**Estado:** mapa relacional **candidato**, sujeto a contrastación; no es un contrato de datos ni una ontología adoptada.

## Propósito

Explicar cómo los conceptos de TDidacta se vinculan entre sí **sin redefinir los conceptos** (Foundations), **las operaciones** (Mechanisms) ni el **ciclo de trabajo** (Lifecycle).

- [Mapa relacional candidato](pedagogical-resolution-relations.md): relaciones entre necesidad, intención, espacio de posibilidades, exploración, realización, resultados y revisión.

- [Espacios de posibilidades](../foundations/possibility-spaces.md).
- [Exploración y realización](../foundations/exploration-and-realization.md).
- [Resolución recursiva](../foundations/recursive-pedagogical-resolution.md).

**Regla de interpretación:** una relación propuesta no obliga a crear una clase, una tabla, un archivo ni una etapa de proceso. La autoridad y madurez de cada concepto siguen en sus fuentes.
