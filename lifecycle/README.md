# Lifecycle — ciclo de trabajo pedagógico

**Estado:** candidato. Esta superficie propone cómo coordinar fundamentos, mecanismos y relaciones de TDidacta a través de iteraciones; **no declara un proceso obligatorio**.

## Documento

- [Resolución recursiva de necesidades pedagógicas](recursive-pedagogical-resolution.md): necesidad → intención → espacio → operaciones → resultados, posibles revisiones y nuevas necesidades.
- [Comparación visual Mermaid / SVG](visual-comparison-mermaid-svg.md): dos representaciones experimentales del mismo lifecycle candidato para evaluar claridad y mantenibilidad; no altera el modelo.

## Fronteras

- [Foundations](../foundations/README.md) define conceptos.
- [Mechanisms](../mechanisms/README.md) describe espacios y operaciones para explorar o realizar.
- [Relationships](../relationships/README.md) explica sus vínculos.
- **Lifecycle** se ocupa de coordinar esos vínculos cuando se aborda una necesidad.

No presupone una etapa fija, escala inicial ni equivalencia validada con VSlices o PResolver.
