# Productos y responsabilidades abiertas

**Estado:** propuestas existentes; fronteras todavía no consolidadas.

TDidacta contempla provisionalmente la familia **Method, Design, Docs Standard, Framework y Platform**. Que esta división aparezca en otros flavors de PResolver no demuestra que sea correcta o estable para TDidacta.

También permanecen abiertas preguntas sobre:
- propiedad y formulación de la intención pedagógica;
- relación de la intención con sus realizaciones;
- autonomía de quien aprende;
- representaciones intermedias como TDIR.

La investigación puede aportar evidencia, pero sus conceptos candidatos no se transforman automáticamente en especificaciones adoptadas.

La estructura de productos deberá crecer cuando se identifiquen responsabilidades justificadas. **No se crearán superficies únicamente por analogía con VSlices u otros sistemas.**
